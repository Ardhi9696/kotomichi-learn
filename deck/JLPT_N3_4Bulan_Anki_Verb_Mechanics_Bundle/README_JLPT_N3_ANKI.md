# JLPT N3 4 Bulan — Verb Mechanics Deck

Isi:
- 60 kartu Recognition: Japanese → meaning + class + transitivity + frame.
- 60 kartu Production: Korean/English → Japanese.
- Master TSV untuk diedit atau diimpor ke Notion.

Import:
1. Anki Desktop → File → Import.
2. Pilih TSV.
3. Separator: Tab.
4. Note type: Basic.
5. Field 1 = Front, Field 2 = Back, Field 3 = Tags.
6. Aktifkan Allow HTML in fields.
7. Buat dua subdeck: Recognition dan Production.

Aturan belajar:
- Ucapkan particle frame setiap menjawab.
- Hafalkan pair bersama-sama: Nを開(あ)ける ↔ Nが開(あ)く.
- Jangan buat kartu terpisah untuk semua konjugasi; lakukan drill konjugasi terpisah.
- Mulai 15 Recognition + 5 Production baru per hari.
